## Purpose

支持外部烤机工具在隔离用户目录中运行打包游戏端，以实际界面点击选择指定游戏，同时可关闭非测试范围的会员房间连接，保留普通产品的默认行为。

## ADDED Requirements

### Requirement: 隔离运行可关闭房间连接
游戏端 SHALL 保留默认开启房间连接的行为，并允许显式配置关闭，不要求启动会员平台。

#### Scenario: 显式关闭
- **WHEN** 隔离测试配置关闭房间连接
- **THEN** 自有后端收到关闭配置，普通未配置启动仍开启

### Requirement: 轮播可观察
游戏端 SHALL 为现有轮播方向与选中游戏提供稳定标识，不添加绕过 UI 的开局入口。

#### Scenario: 切换指定游戏
- **WHEN** 点击现有方向按钮
- **THEN** 选中标识反映实际居中游戏 ID，原交互与超时行为保持不变

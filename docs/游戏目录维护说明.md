# 游戏目录维护

- 删除分类：在分类卡片点“删除”并确认。所属游戏保留，变为未分类，可从“游戏 → 游戏列表”找到。
- 编辑游戏：鼠标移到游戏卡片，点底部“编辑”进入编辑器。名称、封面、分类和触屏显示在编辑器中修改。
- 调试游戏：点卡片中央播放按钮，直接进入调试页。可选人数、关卡、直接/手环启动；退出返回原列表。编辑器不再提供启动按钮。
- 导出游戏：点卡片底部“导出”，选择保存位置。JSON 是完整的一条游戏表记录，包含全部关卡，不是编辑器的当前关卡 JSON，也不是数据库备份。图片、音频、视频及独立精灵库文件不随行复制。
- 新建和导入：分类首页、分类内和游戏列表均可操作。点“导入游戏”，先选娱乐挑战或排位赛，再选上面导出的 JSON。类型不匹配会提示；导入成功新增游戏，不覆盖原游戏。同名自动加后缀，初始为未分类，排在原游戏之后，可从游戏列表找到。
- 删除游戏：点卡片底部“删除”并确认。只删除该游戏记录，不删除共享资源或会员历史；使用中/排队中的游戏不能删除。删除后刷新或重启不会自动补回，需要保留配置可先导出。

卡片右上角手柄仍用于拖动排序。取消导入、导出或删除，不会修改游戏数据。

编辑器的关卡标签悬停或键盘聚焦时显示删除叉号，确认后删除该标签对应的关卡，至少保留一关。删除其他关卡时保留当前关卡及帧草稿。

共用编辑器选择工具用于选择和移动对象，画笔用于单格或框选创建，橡皮删除碰到的整个对象；一次连续擦除可整体撤销。关卡预览显示逐格边线，GIF导出保留原像素。Rank 的 X 范围、Y 范围使用 `min,max`，坐标从 1 开始。

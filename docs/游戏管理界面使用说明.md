# 游戏管理界面

- 点击顶部“游戏”，再选“首页”或“游戏列表”。应用启动默认显示首页；“进入游戏”位于“副屏”之后。
- 首页的一级菜单是横向卡片，点击进入该分类；右下角铅笔修改名称和封面。
- 分类与游戏排序：鼠标移到卡片右上角，按住出现的六点手柄拖到目标卡片，松开后自动保存。保存期间不能再次拖动；失败会恢复原顺序并显示原因，刷新后可重试。分类内排序只调整该分类可见游戏，其他游戏位置不变。
- 更换封面：选择图片，展开文件夹，再选择图片。可双击确认，或选中后点确认；取消不改变原值。同名文件可通过完整相对路径区分。
- 图片、GIF、应用图标、副屏背景和待机画面保留选择/替换，不再提供清除按钮。音频清除等其他操作不变。
- 媒体库目录使用文件夹图标；图片保持比例居中，最大显示宽高为原容器适配尺寸的一半。此变化不影响游戏、副屏、编辑器或视频显示。
- 新增精灵可选择绿、蓝、红、紫四种颜色，保存后刷新仍保留。已有精灵预览及点阵编辑按其保存颜色显示；编辑点位不会改颜色。非基础精灵不再显示“自定义”，基础精灵仍显示基础标志。
- 点击“语言”直接弹出选择窗口。选择成功或选择当前语言后关闭，取消/Escape 不更改语言；保存失败可重试。当前页面和未保存编辑内容保留，关闭后可继续输入。

## 开发验证

运行 `pnpm test` 与 `pnpm build`。在三仓库工作区中运行 `node scripts/test-catalog-library-ui.mjs`，使用 platform 现有 Playwright 与本机 Chromium 做真实界面点击/拖动测试，不访问人工数据库；截图和结果写入 `.build/catalog-library-ui/`。

重新打包游戏端后，可运行 `node scripts/test-catalog-library-packaged.mjs` 验证真实 EXE 的菜单、排序、封面、语言和四色精灵，以及关闭再启动后的数据保留。它在 `.build/catalog-packaged-*` 建立独立用户目录、媒体和数据库，不连接会员管理端或真实控制器；不会修改日常使用的数据。

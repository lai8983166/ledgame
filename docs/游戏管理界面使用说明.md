# 游戏管理界面

- 点击顶部“游戏”，再选“首页”或“游戏列表”。应用启动默认显示首页；“进入游戏”位于“副屏”之后。
- 首页的一级菜单是横向卡片，点击进入该分类；右下角铅笔修改名称和封面。
- 分类与游戏排序：鼠标移到卡片右上角，按住出现的六点手柄拖到目标卡片，松开后自动保存。保存期间不能再次拖动；失败会恢复原顺序并显示原因，刷新后可重试。分类内排序只调整该分类可见游戏，其他游戏位置不变。
- 更换封面：选择图片，展开文件夹，再选择图片。可双击确认，或选中后点确认；取消不改变原值。同名文件可通过完整相对路径区分。
- 图片、GIF、应用图标、副屏背景和待机画面保留选择/替换，不再提供清除按钮。音频清除等其他操作不变。
- 媒体库目录使用文件夹图标；图片保持比例居中，最大显示宽高为原容器适配尺寸的一半。此变化不影响游戏、副屏、编辑器或视频显示。
- 新增精灵可选择绿、蓝、红、紫四种颜色，保存后刷新仍保留。已有精灵预览及点阵编辑按其保存颜色显示；编辑点位不会改颜色。非基础精灵不再显示“自定义”，基础精灵仍显示基础标志。
- 点击“语言”直接弹出选择窗口。选择成功或选择当前语言后关闭，取消/Escape 不更改语言；保存失败可重试。当前页面和未保存编辑内容保留，关闭后可继续输入。

## 配置与触屏显示

- 页面、编辑器和配置弹窗保留主标题，不再显示英文对照或装饰性副标题。分类名、正在编辑的游戏名、资源路径、计数和错误提示保留；Touch/副屏待机画面不变。
- 配置页已加宽，桌面窗口标签与输入同行，窄窗口自动换行。会员管理端只填写 IP/主机名；新配置使用 8090，旧配置中有效的自定义端口仍保留，保存、测试连接和下次启动不会偷偷改端口。
- 调试助手只保留“布线工具”和“调试工具”，默认进入布线。“单行、单列、折返行、折返列”只改名称，不改布线算法。
- 新生成的打包配置与调试草稿默认 GRB；已有 conf.json 的显式 RGB 等合法线序不被改写。打包默认仍是 16×36、折返行、TCP 3003，自动网卡映射不变。需要其他硬件配置时仍可维护 elc408/conf.json，再重新加载/启动。
- 调试页操作台和日志分区展示。每个控件同行；长日志可以展开/收起，保留完整 hex、时间、方向、类型与捕获状态。切离调试工具停止日志采样，不改变发送/停止行为。
- 游戏信息中的“触屏显示”点击后立即独立保存，影响所有 Touch 玩家选择与排队选择，不再等待会员管理端儿童模式。保存失败恢复原值并提示；取消其他未保存的名称、封面、分类不撤销已成功保存的开关。
- 历史 `childModeVisible=false` 升级后会直接隐藏，管理列表仍可编辑并重新开启。缺省/null/true 显示，不迁移或批量改数据库。隐藏不是启动权限，编辑器仍能调试该游戏。
- 已打开的 Touch 窗口自动刷新目录。准备中的已选游戏确实被隐藏时取消准备并释放访问；刷新失败保留原选择，可点“重新加载”。正在运行的游戏、已入队任务、积分和扣时不受开关影响。

## 本次验证

运行 `node scripts/test-settings-touch-ui.mjs` 检查配置、硬件助手、即时开关和六种 Touch 入口；截图/结果在 `.build/settings-touch-ui/`。接口均模拟，不发送真实控制器命令。

打包后运行 `node scripts/test-settings-touch-packaged.mjs`，验证真实 EXE、多窗口更新、准备取消、隐藏游戏调试、重启保留与打包默认文件。它使用 `.build/settings-touch-packaged-*` 的独立用户目录和 H2 数据库，SDK 和门店连接禁用，不访问人工数据库。

## 既有界面回归

运行 `pnpm test` 与 `pnpm build`。在三仓库工作区中运行 `node scripts/test-catalog-library-ui.mjs`，使用 platform 现有 Playwright 与本机 Chromium 做真实界面点击/拖动测试，不访问人工数据库；截图和结果写入 `.build/catalog-library-ui/`。

重新打包游戏端后，可运行 `node scripts/test-catalog-library-packaged.mjs` 验证真实 EXE 的菜单、排序、封面、语言和四色精灵，以及关闭再启动后的数据保留。它在 `.build/catalog-packaged-*` 建立独立用户目录、媒体和数据库，不连接会员管理端或真实控制器；不会修改日常使用的数据。

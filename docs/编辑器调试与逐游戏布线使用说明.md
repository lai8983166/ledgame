# 编辑器调试与逐游戏布线

## 进入调试

在“游戏 → 游戏列表”打开一个游戏的编辑器，点击“启动游戏”，进入主窗口内的调试页面。不会为这个入口打开 Touch 或 DebugPanel 窗口，副屏仍可观察同一局游戏。

若有未保存内容，可以选择“保存并进入调试”“使用已保存版本”或“取消”。使用已保存版本不会丢掉编辑草稿；退出后仍回到原编辑器。调试运行的是数据库中的版本，不是未保存草稿。

左侧选启动方式、人数、起始关卡，右侧显示本游戏尺寸的 RGB。关卡在界面从 1 开始。开始后设置锁定，点击 RGB 格子会调用原来的模拟踩踏接口，并非页面自行加分。游戏内分数与累计会员奖励积分分别显示；Rank 逐玩家显示颜色与分数，没有生命值的玩法显示“—”。有限时间显示秒数，否则显示“无限”。

Rank 自带的整局时长也显示实时倒计时；若同时启用额外全局时限，显示两者中更早到期的剩余时间，不会把“未开启额外时限”误写成无限。

## 直接启动和手环启动

- 直接启动：不需要会员管理端、读卡器或地砖控制器。
- 手环启动：需要连接会员管理端。选人数，点击“请刷手环”，读卡器输入真实 UID 并发送回车后完成一次扫描；每名玩家都要刷不同且有效的会员手环。数量不足不能开始。取消提示不算扫描成功。

读卡只在刷卡提示打开时接收；正常输入人数、关卡不会被吞掉。手环调试会产生真实准入和游玩记录，请用专门的手动测试会员。页面显示平台提供的会员身份和手环余额，不制造手环 ID。

## 暂停、重新开始、退出

- 暂停/继续：冻结实际玩法、帧、游戏/关卡时钟、Rank 效果及相关音频/地砖动画；启动和结算阶段也支持。暂停期间的踩踏不积压，恢复后不补执行。
- **暂停游戏不等于暂停手环计费**：余额仍按会员管理端现行规则计算。本次没有改变计费策略，游戏倒计时与购买时长是两个不同数值。
- 重新开始：先正常终止并清理旧局，再创建新会话。手环模式须重新刷卡、重新准入，不能沿用旧局已通过的检查。分数、生命、奖励和计时重新初始化。
- 左上角退出：先取消本页准备或停止本页游戏，成功后才返回编辑器。若失败，保留页面和错误，重试即可。自然结束也留在本页展示结果，不自动返回。

有其他游戏、准备会话或待启动队列时拒绝进入/启动，不强行结束营业游戏。本页只控制自己的会话，原顾客触屏、排队及烤机入口仍保留。

## 每个游戏的地砖布线

编辑器点击“地砖布线”，复用原布线工具。宽高来自游戏且在工具中锁定；可选单行、单列、折返行、折返列，调整通道和点位，再点击“保存此游戏布线”。取消不写数据库。

第一次打开：已有独立布线就读取它；否则尝试复制尺寸相符的全局 `elc408/wiring.json` 作为草稿。全局尺寸不符时给空白草稿，不裁掉旧点位。不点击保存就仍使用全局布线。

保存只修改本游戏的 `wiringData`，不顺带保存 RGB 编辑草稿，也不改其他游戏、全局文件或符号灯布局。若改了场地尺寸，先保存游戏尺寸，再保存匹配的布线；重复、越界、容量超限或格式错误会被拒绝。允许只布线部分格子。

下次启动时冻结此游戏布线快照，RGB 输出与踩踏反向坐标使用同一映射；当前局不热更新。结束后恢复全局待机布线。控制器型号、网卡、端口和 RGB 线序仍使用全局 `conf.json`，没有逐游戏复制网络配置。

旧游戏缺少 `runtimeEnabled=true` 时继续全局回退，旧示例单点不会自动生效。独立配置随游戏数据同步/导入导出保留，无需批量迁移数据库。

## 硬件异常

调试固定使用 SIMULATION。SDK 关闭、配置加载失败或映射切换失败时，仍可看 RGB 和模拟点击，但会显示原因并停用该局 SDK 输出，不能用另一游戏的映射继续发帧。正常硬件业务模式仍按原规则拒绝无效启动。

搜索仍沿用原协议，配置多个控制器时不要求必须搜到全部控制器才发送。自动化验证使用模拟报文和隔离数据；未连接真实设备，不代表已完成真实地砖验收。

## 自动化复验

游戏前端目录：`pnpm test`、`pnpm build`、`node scripts/test-editor-debug-ui.mjs`。

游戏后端目录：`mvn test`。

平台目录的真实会员联调（使用随机端口、隔离 SQLite/H2，不读取业务库）：先设置 `LEDGAME_TEST_LICENSE_PATH` 为本机有效授权文件路径，然后运行：

```text
pnpm exec playwright test --config acceptance/playwright.config.ts editor-debug-workspace.spec.ts
```

真实打包版冒烟：游戏前端目录运行 `node scripts/test-editor-debug-packaged.mjs`。测试使用新的临时游戏用户目录，不修改日常游戏库。
